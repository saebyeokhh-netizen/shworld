---## 요청

> 화면을 닫아서 다른 앱을 켰을 때 30초 뒤에 배경 음악이 끊기게 해줘.
> 오디오 시계에 얘기해서.

## 예전 동작

화면이 가려지는 **즉시** 껐다.

```ts
if (document.hidden) stopMusic();
else syncMusicToPreference();
```

카카오톡을 보는 내내 음악이 흐르는 것은 막아야 하니 방향은 맞았지만, 실제로는 **몇 초 만에
돌아오는 일이 훨씬 잦다** — 방 코드를 보내러 갔다 오는 것이 대표적이다. 그때마다 음악이
끊겼다가 돌아오면 **처음부터 다시** 시작하니 오히려 거슬렸다.

## 왜 보통 시계로는 안 되는가

"30초 뒤에 꺼라" 를 `setTimeout` 으로 적으면 될 것 같지만 안 된다. **화면이 가려지면
브라우저가 `setTimeout` 을 뒤로 미룬다.** 배터리를 아끼려는 동작인데, 그 탓에 30초로
적어둔 것이 1분 뒤에 울릴 수 있다. 그동안 음악은 계속 흐른다. 정확히 우리가 막으려던 상황이다.

## 오디오 시계에 맡긴다

**소리를 줄이는 일**은 오디오 장치의 시계에 예약한다. 이 시계는 소리가 나는 동안 정확히
흐르고 미뤄지지 않으므로, 화면이 꺼져 있어도 30초에 정확히 줄어들기 시작한다.

```ts
gain.gain.setValueAtTime(gain.gain.value, now);
gain.gain.setValueAtTime(gain.gain.value, now + AWAY_GRACE);  // 30초 동안 그대로
gain.gain.linearRampToValueAtTime(0, now + AWAY_GRACE + FADE); // 그 뒤 서서히 0
```

보통 시계는 **이미 조용해진 뒤 뒷정리**(재생 장치를 실제로 멈추는 일)에만 쓴다. 그 일이
늦어지는 것은 아무도 모른다.

## 30초 안에 돌아오면 — 끊긴 적이 없다

되살릴 때 처음부터 다시 틀지 않는다. 음악은 계속 나고 있었으므로 **볼륨만 되돌린다**
(0.3초). 듣는 사람은 자리를 비웠던 것조차 모른다.

```ts
else if (!resumeFromAway()) syncMusicToPreference();
```

`resumeFromAway()` 가 false 를 돌려주는 경우는 둘이다 — 이미 30초가 지나 꺼졌거나, 애초에
음악이 안 나고 있었거나. 그때는 예전처럼 평소대로 다시 튼다.

## 확인

- 타입 통과, 화면 테스트 376개 통과, 배포 완료
- **자동 검사는 붙이지 못했다.** 소리가 실제로 줄어드는지는 진짜 오디오 장치가 있어야
  확인할 수 있는데, 시험 환경에는 그것이 없어 함수들이 앞에서 그냥 돌아온다. 가짜 장치를
  끼우려면 이 모듈의 구조를 꽤 바꿔야 해서, 얻는 것보다 드는 비용이 컸다.
  **폰에서 직접 확인이 필요하다** — 음악이 나는 중에 다른 앱으로 갔다가
  (1) 10초 뒤 돌아오면 끊김 없이 이어지는지, (2) 40초쯤 두면 조용해져 있는지.

## 덧붙임 — "안 꺼진다" 는 제보

배포 뒤 음악이 계속 흐른다는 제보를 받았다. 확인한 것과 추론은 이렇다.

**배포는 올라가 있었다.** 실서버 번들과 방금 빌드한 번들이 이름·크기까지 같았다. 모듈이
여러 조각으로 쪼개져 상태가 둘로 갈리는 경우도 아니었다(조각이 하나다).

**막는 장치가 이미 둘이었다는 점이 단서다.**

1. 오디오 시계에 예약한 볼륨 줄이기 (30초)
2. 보통 시계로 재생 자체를 멈추는 뒷정리 (약 31초)

둘은 서로 다른 시계를 쓰므로 한쪽이 멈춰도 다른 쪽이 듣는다. **그런데도 소리가 계속
났다면, 둘을 예약하는 코드가 애초에 불리지 않았다**는 뜻이다. 즉 화면이 가려졌다는
신호(`visibilitychange`)가 오지 않았다.

이것은 알려진 문제다. 홈 화면에 설치한 앱이나 안드로이드 웹뷰에서는 다른 앱으로 넘어가도
그 신호가 오지 않는 경우가 있다.

### 고친 방법 — 신호를 셋 듣는다

`visibilitychange` 에 더해 창이 초점을 잃는 것(`blur`)과 페이지가 뒤로 물러나는 것
(`pagehide`)도 자리 비움으로 친다. 셋 중 하나만 와도 된다. 이미 예약이 걸려 있으면
`scheduleAwayStop` 이 그냥 돌아가므로 여러 번 와도 탈이 없다.

초점만 잃은 경우(PC에서 다른 창을 클릭)도 자리 비움으로 치지만, 30초를 기다려 주므로
잠깐 딴 창을 봤다고 음악이 끊기지는 않는다.

## 받은 것

`sound/` 에 세 갈래가 들어왔다.

- **메두사 미용실 사운드 팩 v1** — 우리 게임의 상황 이름이 그대로 붙은 14개
  (카드 내기·예측 확정·트릭 승패·라운드 성패·승리·패배 …). 직접 합성한 원본이라 자유롭게 쓴다.
- **Kenney** 카지노/UI 오디오 — 전부 CC0
- **이모티콘용 목소리 넷** — Pixabay·Freesound 계열

## Kenney 는 쓰지 않았다

받아두긴 했는데, **우리 팩이 이미 우리 상황에 딱 맞게 이름 붙여 들어왔다.** 여러 출처를
섞으면 소리의 결이 제각각이라 한 게임에서 나는 소리 같지가 않다.

기술적인 이유도 하나 있다. Kenney 파일은 `.ogg` 인데 **옛 아이폰 사파리는 ogg 를 못 읽는다.**
우리 팩은 WAV 로 왔고, 어차피 변환할 것이라 형식 걱정이 없다.

## 만드는 과정 — `tools/make-sounds.mjs`

이 컴퓨터에 ffmpeg 이 없다. 그런데 **크로미움의 Web Audio 가 wav·mp3·ogg·m4a 를 다 읽는다.**
그것으로 다섯 가지를 한다.

1. **앞뒤 무음을 잘라낸다.** 받아온 이모티콘 음원은 앞에 0.1~0.8초씩 조용한 구간이 붙어
   있었다. 그대로 넣으면 눌렀는데 소리가 반 박자 늦게 난다.
2. 너무 길면 자른다 — 이모티콘은 1초 안쪽. 한 판에 여러 번 나는 소리가 길면 거슬린다.
3. **모노 22.05kHz 로 낮춘다.** 짧은 효과음에 스테레오 44.1kHz 는 과하다. 귀로는 차이가
   거의 없는데 파일은 4분의 1이 된다.
4. 앞뒤에 6ms 페이드 — 파형 한가운데를 자르면 '툭' 하는 잡음이 남는다.
5. 볼륨을 미리 먹여 굽는다. 팩에 딸린 권장값(UI 0.4 / 카드 0.55 / 결과 0.8)을 따랐다.

원본 1.7MB → **16개 합쳐 480KB**.

## 합성음을 버리지 않았다

파일을 받아오기까지 잠깐 걸리고, 못 받아올 수도 있다. 그때는 **옛 합성음이 난다.**
소리가 조금 다른 것과 아무 소리도 안 나는 것은 다르다.

받아오는 시점은 **첫 재생 때**다. 앱이 뜰 때 받으면 첫 화면이 그만큼 늦는데 소리는 게임에
들어가야 쓰고, 브라우저는 어차피 사람이 화면을 한 번 건드리기 전에는 소리를 못 내게
막는다. 그러니 첫 재생 시점에 받기 시작해도 늦지 않다.

## 소리를 붙인 자리

기존 여섯에 더해 새로 일곱을 붙였다.

| 언제 | 소리 | 왜 |
| --- | --- | --- |
| 카드를 **고를** 때 | card-select | 냈을 때와 달라야 아직 안 낸 것이 구분된다 |
| **내 차례**가 올 때 | turn-alert | 남의 차례를 기다리다 눈을 떼고 시간초과로 AI 에게 넘어가는 일이 준다 |
| 시간이 얼마 안 남았을 때 | timer-warning | 진동과 같은 조건. 폰을 상 위에 두고 보는 사람도 있다 |
| 라운드 **적중** | round | |
| 라운드 **빗나감** | round-miss | 정산표는 숫자가 많아 한눈에 안 읽힌다. 소리가 먼저 알려준다 |
| 판을 **이김** | game-win | |
| 판을 **짐** | game-lose | 최종 결과는 등수가 줄줄이라 자기 자리를 찾아야 한다 |

라운드 성패를 **이긴 트릭 수가 아니라 예측 적중 여부**로 가른 것이 중요하다. 이 게임은
많이 이기는 게 아니라 **말한 만큼 이기는** 것이 목적이다.

다 같이 그만둔 판(`aborted`)에는 승패 소리가 울리지 않는다. 이긴 것도 진 것도 아니다.

## 확인

브라우저에서 연습 게임을 열어 **16개 음원이 모두 받아지는 것**을 확인했다.

## 남은 것

- **화남 이모티콘 소리**는 받은 파일이 "그건 거짓말이야" 라는 말소리라 조금 어색할 수 있다.
  들어보고 어색하면 다른 것으로 바꾸면 된다 — 파일만 갈아 끼우고 도구를 다시 돌리면 끝이다.
- 특수카드 전용 소리(메두사 역전·제우스)는 아직 안 붙였다. 언제 울릴지가 규칙과 얽혀 있어
  따로 봐야 한다.
