---## 1. 최종 결과를 그림으로 (카메라 버튼)

최종 결과 팝업 오른쪽 위에 카메라 버튼을 달았다. 누르면 공유 시트가 열려 카카오톡으로 바로
보낼 수 있고, 공유가 안 되는 환경에서는 PNG 로 저장된다.

**화면을 찍지 않고 새로 그린다.** 웹에는 "이 요소만 캡처" 하는 방법이 없다. 화면 전체를 찍는
API 는 권한 팝업이 뜨고 뒤에 깔린 게임판·상태바까지 함께 찍힌다. 남의 화면을 옮겨 그리는
라이브러리(html2canvas 류)는 200KB 가 넘고 폰트·그림자에서 자주 어긋난다.

결과에 들어가는 것은 등수·이름·점수뿐이라, 그 숫자로 캔버스에 새로 그리는 편이 가볍고
결과도 예측 가능하다. 자랑하려고 올리는 그림이니 화면보다 정갈해도 된다.

- 800px 폭, 2배 해상도로 그려 메신저에서 줄어들어도 읽힌다
- 1등은 골드, **내 줄은 골드 테두리** — 그림만 봐도 누가 나인지 알 수 있어야 한다
- 아래에 "스쿨킹" 을 남긴다
- `createResultImageBlob` 을 따로 내보내 브라우저에서 그림만 눈으로 확인할 수 있게 했다.
  캔버스에 직접 그리는 코드는 봐야 어긋난 자리가 보인다.

## 2. 게임 중에는 아래 시스템 막대를 숨긴다

안드로이드의 뒤로·홈·최근 막대가 게임판 아래를 계속 차지했다. 카드가 손에 닿는 자리라
실수로 홈으로 나가기도 쉽다. 게임 화면에 들어가면 전체화면으로 들어가고, 나가면 원래대로
돌아온다. 화면 아래에서 위로 쓸어올리면 막대가 잠깐 다시 나온다.

**앱 전체가 아니라 게임 화면만이다.** 홈이나 설정에서까지 숨기면 나가는 길이 안 보여
답답하다. 몰입이 필요한 곳은 판이 도는 동안뿐이다.

전체화면 요청은 사용자가 방금 무언가를 눌렀을 때만 받아들여진다. 게임 화면은 언제나 버튼을
눌러 들어오므로 대개 통과하고, 거절당해도 조용히 넘어간다(막대가 보일 뿐이다).

> 작업 중 하나 잡았다. 이 훅을 처음에 조기 반환(`게임을 준비하는 중…`) **아래**에 넣었는데,
> 그러면 로딩 화면이 그려질 때 훅 호출 순서가 달라져 리액트가 터진다. 훅은 조기 반환보다
> 위에 있어야 한다.

## 3. 글자 선택 → 구글 검색 막대가 뜨던 것

카드를 고르거나 버튼을 꾹 누를 때마다 글자가 선택되고, 그 위로 "복사 / 공유 / 웹 검색" 막대와
구글 검색창이 따라 올라왔다. 게임에서 글자를 복사할 일은 없으므로 통째로 껐다.

다만 **입력칸은 예외**다 — 친구 코드나 방 코드는 붙여넣고 다시 읽어야 한다.

## 4. 트로피 = 누적 점수, 코인 = 0

트로피 2,480 과 코인 1,240 은 목업 숫자였다.

- **트로피**는 이제 지금까지 한 **모든 판의 점수 합**이다. 로그인했으면 계정 기록에서,
  아니면 이 기기 기록에서 계산한다 — 전적 화면과 같은 저장소라 두 숫자가 어긋나지 않는다.
  예측이 빗나가면 깎이는 규칙이라 **음수도 그대로 보여준다**. 깎였다는 사실이 다음 판을 하게
  만드는 이유다. (요약에 `totalScore` 를 더하고 테스트도 붙였다)
- **코인은 0** 이다. 얻을 방법도 쓸 곳도 아직 없다. 지어낸 잔액을 보여주면 "있는데 왜 못
  쓰지" 가 되고, 진짜 잔액이 붙는 순간 갑자기 줄어든 것처럼 보인다. 스킨상점·코인충전
  화면의 목업 잔액도 함께 0 으로 맞췄다.

## 남은 것 — 코인 경제

코인을 **어떻게 얻게 할지**가 정해지지 않았다. 이건 코드보다 결정이 먼저다.

- 광고 보상은 광고 네트워크(AdMob 등) 심사와 정책이 따라오고,
- 실결제는 결제대행 계약·수수료·환불 규정·전자상거래 표기 의무가 따라온다.
- 출석 보상처럼 게임 안에서만 도는 재화는 지금 당장, 무료로, 우리 서버만으로 된다.

무엇을 먼저 할지 정해지면 그때 잔액을 계정에 붙인다.
