개인정보처리방침

이 사이트(shworld.cloud)가 무엇을 받아 어디에 두는지, 남에게 무엇을 넘기는지, 지우고 싶을 때 어떻게 하는지 적어 둡니다.

한눈에

언제 받는 것 왜
방명록에 글을 남길 때 이름, 메시지 그 글을 다른 방문자에게 보여주려고
연락 양식을 보낼 때 이름, 이메일, 메시지 답장하려고
작품 페이지를 열 때 없음 (숫자만 1 오름) 어떤 작품이 읽히는지 알려고
그냥 둘러볼 때 없음 —

회원가입이 없습니다. 로그인도, 비밀번호도 받지 않습니다. 위의 두 자리에서 직접 적어 보내신 것 말고는 이 사이트가 따로 모으는 것이 없습니다.

IP 주소는 저장하지 않습니다

한 사람이 같은 글을 수십 번 올리는 것을 막으려면 같은 사람인지는 알아야 합니다. 그런데 그 목적에 IP 주소 자체가 필요하지는 않습니다.

그래서 IP 에 비밀 값을 섞어 되돌릴 수 없는 형태로 뭉갠 뒤 그 결과만 저장합니다(SHA-256). 저장된 값에서 원래 IP 를 알아낼 수 없고, 도배를 세는 것 말고 다른 데 쓰지 않습니다. 원본 IP 는 어디에도 남지 않습니다.

브라우저에 남는 것

  • shworld:theme — 밝게 볼지 어둡게 볼지 고른 것
  • 작품별 조회 표시 — 한 번 방문에 조회수가 여러 번 오르지 않게 하는 표시

둘 다 브라우저 안에만 있고 서버로 보내지 않습니다. 지우고 싶으면 브라우저의 사이트 데이터 삭제로 없앨 수 있고, 없어도 사이트는 그대로 돌아갑니다.

남에게 넘어가는 것

이 사이트는 서버를 따로 두지 않고 아래 서비스 위에서 돌아갑니다.

  • Cloudflare — 페이지를 내주고, 방명록·연락 내용을 담아 둡니다. 자동 프로그램을 걸러내는 확인 절차(Turnstile)도 여기 것입니다. 사람인지 보는 동안 브라우저와 접속 정보가 Cloudflare 로 갑니다.
  • Google 설문지 — 아래 '지우고 싶을 때' 의 문의 창구가 구글 설문지로 되어 있습니다. 거기 적어 보내신 내용은 구글에 저장되고, 제가 그것을 읽습니다. 문의를 보내지 않으시면 이 경로로 넘어가는 것은 아무것도 없습니다.
  • Google AdSense — 광고를 띄웁니다. 광고를 고르는 과정에서 쿠키와 광고 식별자가 쓰일 수 있습니다. 이 부분은 구글이 정하는 방식을 따르며, 무엇을 어떻게 쓰는지는 구글 광고 정책에 적혀 있습니다. 광고 개인화는 내 광고 센터에서 끌 수 있습니다.

이 셋 말고 다른 곳에 넘기거나 파는 일은 없습니다. 방문자를 따라다니는 분석 도구도 붙이지 않았습니다.

얼마나 두는지, 지우고 싶을 때

방명록과 연락 내용은 따로 지우기 전까지 남아 있습니다. 기한을 정해 두고 자동으로 비우지 않습니다.

방명록 글을 내리면 목록에서는 사라지지만 보관된 줄 자체는 남습니다. 스팸 신고에 대응하거나 잘못 지운 것을 되돌리기 위해서입니다. 흔적까지 완전히 지우기를 원하시면 말씀해 주세요. 그렇게 해 드립니다.

무엇을 남겼는지 보고 싶거나, 고치거나 지우고 싶으시면 아래 창구로 알려 주세요. 어느 글인지 찾을 수 있게 적으실 때 쓰신 이름과 대략의 시기를 함께 적어 주시면 빠릅니다.
