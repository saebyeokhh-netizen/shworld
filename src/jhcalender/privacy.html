정희달력 개인정보처리방침

윈도우용 프로그램 정희달력(jhcalender) 에 적용됩니다. 이 사이트 자체에 대한 방침은 shworld 개인정보처리방침을 보세요.

정희달력은 사용자의 정보를 모으지 않습니다. 적어 넣은 일정과 설정은 사용자의 컴퓨터 안에만 저장되며 만든 사람에게 전송되지 않습니다. 이 프로그램을 위한 서버는 존재하지 않습니다.

적용일: 2026년 9월 16일

1. 무엇이 어디에 저장되나

일정, 분류, 시간표, 설정은 사용자 컴퓨터의 아래 폴더에 파일로만 저장됩니다.

C:\Users\(사용자)\AppData\Roaming\jhcalender

프로그램은 이 폴더 밖으로 아무것도 보내지 않습니다. 사용자가 직접 폴더를 열어 확인하거나 파일을 지울 수 있습니다 (설정 → 정보 → 설정 폴더 열기).

2. 구글 계정 사용

사용자가 원할 때에만, 담아 둔 일정을 본인의 구글 캘린더로 내보낼 수 있습니다. 쓰지 않으면 구글과 아무런 통신도 하지 않습니다.

  • 요청하는 권한 — https://www.googleapis.com/auth/calendar.events (구글 캘린더의 일정 보기·만들기·수정) 하나뿐입니다.
  • 실제로 하는 일 — 사용자가 이 프로그램에 적어 넣은 일정을 사용자의 캘린더에 만들고, 고칩니다.
  • 하지 않는 일 — 구글 캘린더의 일정을 지우지 않습니다. 사용자의 기존 일정을 읽어 가거나 다른 곳으로 보내지 않습니다.
  • 비밀번호 — 구글 로그인 화면에만 입력되며, 이 프로그램과 만든 사람은 비밀번호를 받지도 볼 수도 없습니다.
  • 접속 증표(토큰) — 사용자 컴퓨터에만 저장되며, 윈도우의 암호화 기능(DPAPI)으로 잠겨 있어 그 컴퓨터의 그 계정에서만 풀립니다.

이 프로그램이 구글에서 받은 정보는 사용자의 컴퓨터를 떠나지 않습니다. 만든 사람은 사용자의 캘린더에 접근할 수 없습니다.

구글 사용자 데이터의 이용은 Google API 서비스 사용자 데이터 정책을 따르며, 제한적 사용(Limited Use) 요건을 준수합니다.

3. 권한을 끊는 방법

언제든 프로그램의 설정 → 구글 → 연결 끊기 를 누르면 저장된 증표가 컴퓨터에서 지워집니다. 구글 쪽에서도 끊으시려면 구글 계정 → 서드파티 앱 및 서비스에서 정희달력을 찾아 접근 권한을 삭제하시면 됩니다.

4. 그림에서 글자 읽기

사진이나 화면을 넣어 일정을 뽑는 기능은 윈도우에 내장된 글자 인식을 사용하며 컴퓨터 안에서만 처리됩니다. 사진이 외부로 전송되지 않습니다.

5. 오류 제보

프로그램 안의 오류 제보하기 는 구글 설문지를 엽니다. 거기에 적어 보내시는 내용은 사용자가 스스로 적어 넣은 것에 한합니다 — 프로그램이 자동으로 무언가를 보내지 않습니다. 보내 주신 내용은 문제를 고치는 데에만 쓰이며 다른 곳에 제공하지 않습니다.

6. 만 14세 미만

이 프로그램은 교사의 업무용으로 만들어졌으며, 만 14세 미만 어린이를 대상으로 하지 않고 어린이의 정보를 알면서 수집하지 않습니다.

7. 방침이 바뀔 때

내용이 바뀌면 이 쪽의 적용일을 고쳐 알립니다.
